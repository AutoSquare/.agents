# QoderCN 全局规则入口

本文件安装到 `~/.qoder-cn/AGENTS.md`，适用于本机所有 QoderCN 会话。项目或子目录中的 `AGENTS.md` 可以补充更具体规则；若发生冲突，优先级为：系统/开发者消息 > 项目/子目录规则 > 本全局规则。

## 常驻硬约束

- 默认使用中文回复；用户明确要求其他语言时除外。
- 执行代码修改前，先阅读项目开发文档或 `docs/` 目录中的约定。
- 代码变更默认需要同步开发文档；若任务明确无需文档更新，在交付时说明。
- 禁止执行 `git add` / `git commit` / `git push`，除非用户在同一条消息里明确要求提交。
- 不伪造论文、引用、DOI、期刊、作者、检索来源或已读全文状态。
- 使用 skills 时，先读取匹配 skill 的 `SKILL.md`，再按其流程执行。

## 主题规则

按主题拆分的规则位于 `~/.qoder-cn/rules/`，由 Qoder 的 rules trigger 机制自动管理：常驻规则随本文件一并加载；模型决策与按路径生效的规则仅注入路径与说明，判断相关后再读取正文，无需在此手动罗列。
